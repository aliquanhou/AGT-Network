# AGT Genesis Node

**AGT-GENESIS-NODE-000001**

This directory contains the permanent, immutable record of the first AGT Network node.

## What This Is

The AGT Genesis Node is the cryptographic origin point of the protocol — analogous to Bitcoin's Genesis Block (`000000000019d6689c085ae165831e934ff763ae46a2a6c172b3f1b60a8ce26f`).

It records:
- The first node identity (Ed25519 public key)
- The first Intelligence Proof (`poi-genesis-000000000000`)
- The first Ledger Block (`blk-genesis-00000000`)
- The human and AI contributors to the protocol's creation
- The founding protocol principles

## What This Is NOT

- ❌ An admin account with special privileges
- ❌ A token pre-mine or founder allocation
- ❌ A legal contract or ownership claim
- ❌ A mechanism for protocol control

The Genesis Node is a **historical record**. The protocol is open. The ledger is the authority.

After v0.36 public release, this record will not be modified. Future protocol versions may add to the historical archive but cannot alter what is recorded here.
