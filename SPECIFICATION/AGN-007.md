# AGN-007: Protocol Fee and Genesis Vault

**Specification Number**: AGN-007
**Title**: Protocol Fee Schedule and Genesis Vault
**Status**: Final
**Version**: 1.0.0
**Date**: 2026-08-01
**Requires**: AGN-000, AGN-002

---

## 1. Purpose

This specification defines the Intelligence Protocol Fee — a fixed, transparent fee on every task reward that sustains the AGT Network — and the Genesis Vault, a time-locked fund for protocol origin attribution.

## 2. Protocol Fee

### 2.1 Fee Schedule

The Protocol Fee is a fixed percentage of every task reward:

```
PROTOCOL_FEE = 2.0% of gross task reward
```

### 2.2 Distribution

| Fund | Share of Fee | % of Reward |
|------|-------------|-------------|
| Network Infrastructure | 50% | 1.0% |
| Ecosystem Development | 25% | 0.5% |
| Genesis Vault | 25% | 0.5% |

### 2.3 Deduction

The fee SHALL be deducted from the gross reward before distribution to participants:

```
net_reward = gross_reward - protocol_fee
```

The fee SHALL be deducted proportionally from each participant share.

### 2.4 Immutability

The fee percentage and distribution ratios SHALL be constants in the protocol. Changing them requires a protocol upgrade (MAJOR version change).

## 3. Genesis Vault

### 3.1 Purpose

The Genesis Vault records the protocol's origin attribution. It receives 0.5% of every task reward. It SHALL NOT grant special privileges to any individual.

### 3.2 Address

```
GENESIS_VAULT_ADDRESS = "agt-genesis-vault-000000000000"
```

This address SHALL be publicly visible on the Intelligence Ledger.

### 3.3 Vesting Schedule

```
VESTING_YEARS = 20
VESTING_EPOCHS = 240 (20 years × 12 epochs/year)
VESTING_RATE = 1 / 240 per epoch (~0.417% per epoch)
```

### 3.4 Release Mechanism

```
vested_pct = min(1.0, epochs_elapsed / VESTING_EPOCHS)
releasable = total_received × vested_pct - total_released
if releasable > 0:
    release(releasable)
```

At each epoch boundary, the vested portion SHALL be calculated. Only the vested portion MAY be released.

### 3.5 Maximum Lifetime Attribution

```
MAX_GENESIS_ATTRIBUTION = MAX_SUPPLY × 0.005
                       = 1,000,000,000 × 0.005
                       = 5,000,000 AGT Credit
```

The Genesis Vault SHALL NOT receive more than this amount over the entire lifetime of the protocol.

## 4. Non-Genesis Funds

### 4.1 Network Infrastructure Fund (1.0%)

Reserved for future node operator incentives, protocol development, and network health monitoring. Allocation rules to be defined in a future AGN.

### 4.2 Ecosystem Development Fund (0.5%)

Reserved for grants, developer tooling, and community initiatives. Allocation rules to be defined in a future AGN.

## 5. Transparency

All fee allocations SHALL be recorded as Ledger Blocks (AGN-002) with `type: "protocol_fee"`. The total accumulated in each fund SHALL be queryable via the API.

## 6. Invariants

1. **Fixed rate**: The Protocol Fee SHALL be exactly 2.0%. It SHALL NOT be changed without a protocol upgrade.
2. **Proportional**: The fee SHALL be deducted proportionally from all participant shares.
3. **Time-locked**: Genesis Vault funds SHALL only be released according to the vesting schedule.
4. **Capped**: Total Genesis Vault deposits SHALL NOT exceed 5,000,000 AGT Credit.
5. **Transparent**: All fee allocations SHALL be recorded on the public ledger.

## 7. Governance Note

The Genesis Vault is governed by protocol rules, not by any individual. The Genesis Architect has no ability to:
- Change the fee percentage
- Accelerate the vesting schedule
- Withdraw unvested funds
- Redirect fee flows to different addresses

These restrictions are enforced by the protocol code, not by trust.
