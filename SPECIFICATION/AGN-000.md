## 1. Purpose

This document defines the conventions used by all AGT Network Specifications (AGN). It establishes the numbering scheme, document structure, normative language, and protocol versioning rules.

## 2. Specification Numbering

Each specification is assigned a unique AGN number in the format `AGN-NNN`. Numbers are assigned sequentially. Once assigned, a number is never reused, even if the specification is later obsoleted.

## 3. Normative Language

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "MAY", and "OPTIONAL" in these specifications are to be interpreted as described in [RFC 2119](https://tools.ietf.org/html/rfc2119).

## 4. Document Structure

Each AGN specification follows this structure:

```
1. Purpose
2. Data Model
3. Field Definitions
4. Validation Rules
5. Cryptographic Primitives
6. Invariants
7. Version History
```

## 5. Protocol Version

The protocol version is a three-part semantic version: `MAJOR.MINOR.PATCH`.

- **MAJOR**: Incompatible protocol changes (e.g., change to PoI formula).
- **MINOR**: Backward-compatible protocol extensions (e.g., new signal type).
- **PATCH**: Clarifications, bug fixes, documentation. No protocol change.

The current protocol version as of this specification is:

```
AGT Protocol v1.0.0 (Genesis)
```

The reference implementation version is `v0.36.1`. The protocol version and reference implementation version are distinct. The specification defines the protocol. The implementation demonstrates it.

## 6. Data Type Conventions

| Type | Definition |
|------|-----------|
| `string` | UTF-8 encoded text |
| `bytes` | Raw byte sequence, hex-encoded in JSON |
| `uint64` | Unsigned 64-bit integer |
| `float64` | IEEE 754 double-precision float |
| `timestamp` | ISO 8601 UTC string (`YYYY-MM-DDTHH:MM:SS.ssssss+00:00`) |
| `hash` | 64-character lowercase hex string (SHA-256) |
| `signature` | 128-character lowercase hex string (Ed25519) |
| `public_key` | 64-character lowercase hex string (Ed25519) |

## 7. Reference Implementation

The reference implementation is at `D:\claude\AGT-Network`. All AGN specifications are normative. Where the reference implementation and a specification disagree, the specification is authoritative.
